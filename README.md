# Lab-3-BCD-Display

Marina Falzone & Jared Rabadam

This project implements a single adder & a multiple adder, intended for a BASYS 3 FPGA Board. It then displays it on a 7-segment display.

To simulate, upload the modules as separate files to Vivado. Make sure they have different names. Upload the test bench as well. For FPGA Implementation, run implementation and generate the bitstream and program the board. Match the board input to the testbench and test your cases.
